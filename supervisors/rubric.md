# Marking rubric: computational chapter (unit A1)

A suggested rubric for the computational part of a project built on this unit.
Adapt the weights to your department's scheme.

| Criterion | Weight | Excellent | Adequate | Weak |
|---|---|---|---|---|
| Correctness of code | 15% | All gates pass; confirmed by supervisor rerun | All gates pass | One or more gates fail |
| Convergence study | 20% | Observed orders over a justified asymptotic range; pre-asymptotic and rounding effects explained | Observed orders reported and close to theory | Single step size, or orders missing |
| Cost and comparison | 15% | Error–cost plot used to answer the question for several targets | Error–cost plot shown | Comparison at one step size only |
| Stability | 10% | Theory and experiment compared; stiffness explained | Stability limits reported | Not discussed |
| Application and interpretation | 25% | Brief answered with evidence; limitations discussed; own contribution clear | Brief answered | Results listed without interpretation |
| Viva | 15% | Explains any line of the code and any result | Explains most | Cannot explain own code |

A student who passes all gates but cannot explain the code in the viva should
not receive marks for code correctness.
